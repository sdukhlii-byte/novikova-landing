# Лендинг: бесплатный пробный урок английского для детей (1–7 классы)

Одностраничный сайт с формой. Заявка попадает в Telegram-группу (или канал) через бота, в форме обязателен ник родителя в Telegram. В карточке заявки есть кнопка «Написать родителю».

## Структура страницы (по методу Шварца)

Рынок репетиторов перегрет обещаниями («заговорит за 3 месяца»), холодный трафик из Meta, поэтому страница строится на **механизме и идентификации**, а не на громком обещании.

1. **Заголовок:** желание («перестанет бояться ошибок и начнёт говорить») + механизм («Найди ошибку»).
2. **Узнавание:** шесть узнаваемых сцен (не читает после года обучения, поправили и обиделся, молчит, скучные уроки, группа 10+, родитель не может помочь), затем причина: страх ошибки.
3. **Новый мир:** как выглядит урок, когда страх уходит, и честная оговорка про сроки.
4. **Механизм:** четыре шага и мини-игра на 3 предложения, которую можно пройти прямо на странице.
5. **Форматы** по классам (из её поста про набор): чтение 1–2 кл., «легко» 3–4 кл., разговорный клуб 5–7 кл., индивидуально.
6. **Преподаватель:** фото, факты с Профи.ру и Instagram, ссылки на оба профиля.
7. **Что отмечают родители**, таблица «привычный урок vs здесь», как пройдёт пробный урок, форма, FAQ с возражениями.

Кнопки записи стоят после каждого смыслового блока, на мобильном есть липкая кнопка (прячется, когда видна форма).

## Как работает заявка

1. Родитель заполняет форму: имя, Telegram (`@username`), возраст ребёнка, страна, по желанию имя ребёнка, время и комментарий.
2. Сервер проверяет данные (ник должен быть валидным Telegram-username, телефон не подойдёт), отбрасывает спам (скрытое поле, лимит 5 заявок за 10 минут с одного IP).
3. Карточка заявки уходит в `LEADS_CHAT_ID` через Bot API, дубль пишется в `data/leads.jsonl`.
4. В Meta уходит событие `Lead`: из браузера через пиксель и с сервера через Conversions API с одним `event_id`, дублей нет.

## Запуск локально

```
cp .env.example .env   # заполните и экспортируйте переменные
node server.js         # http://localhost:3000
```

Без `BOT_TOKEN` и `LEADS_CHAT_ID` сайт работает, а заявки только сохраняются в файл.

## Деплой на Railway

1. Загрузите репозиторий на GitHub (`.env` не загружайте).
2. Railway → New Project → Deploy from GitHub repo, подхватится `Dockerfile`.
3. Variables: все из `.env.example`.
4. Settings → Volumes → Add Volume, Mount Path `/data` (иначе резервная копия заявок стирается при деплое).
5. Settings → Networking → Generate Domain или подключите свой домен и пропишите его в `SITE_URL` (нужен для превью-картинки при шеринге).

### Куда слать заявки

- **Та же группа, что у бота english-tutor-bot.** Возьмите его `TEACHER_CHAT_ID` как `LEADS_CHAT_ID` и тот же `BOT_TOKEN`. Бот должен быть в группе. Кнопки статусов из бота на карточках лендинга не работают, это отдельные сообщения.
- **Канал.** Добавьте бота админом с правом публикации, `LEADS_CHAT_ID` будет `-100…` канала.

Узнать id чата: напишите `/id` боту в группе.

## Деплой на Cloudflare Pages (вместо Railway)

Тот же сайт и та же папка `public`. Вместо `server.js` работают `functions/_middleware.js` (подставляет пиксель, `SITE_URL`, ссылку на бота) и `functions/api/lead.js` (принимает заявку). Dockerfile и `server.js` в этом случае не нужны.

1. Загрузите репозиторий на GitHub.
2. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git, выберите репозиторий.
3. Настройки сборки: Framework preset `None`, Build command пустой, Build output directory `public`, Root directory пустой (корень репозитория, там лежит `functions/`).
4. Settings → Variables and Secrets (Production): `BOT_TOKEN` и `LEADS_CHAT_ID` (как Secret), по желанию `META_PIXEL_ID`, `META_CAPI_TOKEN` (Secret), `META_TEST_EVENT_CODE`, `SITE_URL`, `BOT_LINK`. Если `SITE_URL` не задан, берётся адрес сайта.
5. После изменения переменных сделайте Retry deployment (или новый коммит), переменные подхватываются при деплое.
6. Свой домен: Custom domains → Set up a domain.

**Защита от спама.** Лимита по IP на Cloudflare нет (в Workers нет общей памяти). Работает скрытое поле, а для усиления включите бесплатную капчу Turnstile: Cloudflare → Turnstile → Add widget, добавьте домен сайта, затем `TURNSTILE_SITEKEY` (публичный ключ) и `TURNSTILE_SECRET` (секретный, как Secret) в переменные. Капча появится в форме сама.

**Копия заявок.** Файла на диске нет. Заявка приходит в Telegram. По желанию создайте KV namespace, привяжите его как `LEADS_KV` (Settings → Bindings), и каждая заявка сохранится ещё и туда.

**Локальная проверка:** `npx wrangler pages dev public -b BOT_TOKEN=... -b LEADS_CHAT_ID=...`

## Meta

- `META_PIXEL_ID`: событие `PageView` на загрузке, `FormStart` при начале заполнения, `Lead` после успешной отправки.
- `META_CAPI_TOKEN`: токен из Events Manager → Settings → Conversions API.
- Проверка: временно задайте `META_TEST_EVENT_CODE` и смотрите вкладку Test events, потом удалите переменную.
- Оптимизируйте кампанию на событие `Lead`.
- Ссылки в объявлениях с UTM: `?utm_source=fb&utm_campaign={{campaign.name}}&utm_content={{ad.name}}`. Метки придут в карточке заявки.
- Правила Meta про «личные атрибуты»: в объявлениях не пишите «ваш ребёнок не умеет читать» и подобное. Говорите о результате и формате («Как перестать бояться ошибок на английском»).

## Что проверить перед запуском

- **Факты** на странице взяты с Профи.ру (образование, стаж, курсы, конкурсы) и из Instagram (форматы групп, список преимуществ). Пройдитесь с Натальей по блоку преподавателя и подтвердите каждое утверждение.
- **Блок «Отзывы на Профи.ру»:** три реальных отзыва (рейтинг 5,0), пересказаны своими словами с именем и датой, как на Профи.ру. Отзывов мало и они от 2025 года, поэтому по мере появления новых добавляйте их (можно скриншотами с её разрешения). Отзывы родителей и детей из Instagram можно добавить так же.
- **Пробный урок:** на странице обещан вывод для родителя «как справился и с чего начать». Убедитесь, что она так и работает.
- **«Места ограничены»:** на странице написано только то, что группы небольшие и мест в них немного. Если нужен срок набора, добавляйте только реальный.
- `public/privacy.html`: впишите контакт оператора данных и проверьте текст.
- Название «Miss Novikova» в шапке взято из её Instagram.
- Не добавляйте в текст «1000+ довольных учеников» из шапки её Instagram, пока нет подтверждения цифры.
